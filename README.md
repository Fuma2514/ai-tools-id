Kumpulan AI tools yang praktis dipakai kreator, pekerja lepas, dan UMKM di Indonesia — dengan catatan harga (gratis/berbayar), bahasa Indonesia support, dan cara bayar lokal.

| Tool | Kategori | Gratis? | Bahasa Indonesia | Catatan |

| ChatGPT | Asisten umum | Ya (free tier) | Ya | Free tier cukup untuk tugas harian |
| Claude | Asisten umum / coding | Ya (free tier) | Ya | Kuat untuk naskah panjang |
| Canva AI (Magic Studio) | Desain | Sebagian | Ya | Cocok untuk konten IG/WA |
| CapCut | Edit video AI | Ya | Ya | Auto-caption bahasa Indonesia akurat |

## Cara pakai tabel ini
Pilih tool sesuai kategori + anggaran. Kolom "Gratis?" = `Ya` sepenuhnya gratis, `Sebagian` ada free tier terbatas.
